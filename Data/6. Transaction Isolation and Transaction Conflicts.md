## 🔐 What is Transaction Isolation?

**Transaction isolation** refers to **how well a transaction is protected** from the effects of **other concurrent (happening at the same time) transactions**.

It’s a part of the **ACID** properties of transactions:

- **A**tomicity
    
- **C**onsistency
    
- **I**solation ← 💡 this one
    
- **D**urability
    

Isolation ensures that:

> When two people work with the same data at the same time, **their changes don’t mess each other up**.

---

### 🔄 Isolation Levels (Quick Recap):

|Isolation Level|Prevents|Fast?|Safe?|
|---|---|---|---|
|**Read Uncommitted**|Nothing (risky!)|✅|❌|
|**Read Committed**|Dirty Reads|✅✅|❌❌|
|**Repeatable Read**|+ Non-Repeatable Reads|✅|✅|
|**Serializable**|+ Phantom Reads|❌|✅✅✅|

---

## ⚔️ What are Transaction Conflicts?

**Transaction conflicts** happen when **two or more transactions try to access the same data at the same time** — especially when:

- One is reading, and another is writing.
    
- Or both are trying to write.
    

If not managed well, these conflicts can lead to problems like:

- **Lost updates**
    
- **Inconsistent reads**
    
- **Deadlocks**
    

---

### 🧪 Common Conflict Example:

#### Scenario: Updating a product quantity

- **Transaction A** reads quantity = 10
    
- **Transaction B** reads quantity = 10
    

Now:

- **A adds 5 → writes 15**
    
- **B subtracts 3 → writes 7**
    

Final quantity = **7**, but it **should be 12**  
→ **Conflict: B didn’t know A added more**

---

### 💡 How to Handle Conflicts:

- **Use appropriate isolation levels** (like Repeatable Read or Serializable)
    
- **Use locks** (so one transaction must wait)
    
- **Use optimistic concurrency** (check if data changed before saving)
    
- **Use retry logic** in apps (if conflicts occur, try again)
    

---

### 🧠 Summary

|Concept|Meaning|
|---|---|
|**Transaction Isolation**|Controls how transactions affect each other (via isolation levels)|
|**Transaction Conflict**|Happens when two transactions try to access/change the same data|
